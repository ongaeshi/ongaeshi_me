# 004: 空間位置学習アプリ (a-hougan-ichi-app)

- **コード**: [https://github.com/ongaeshi/a-hougan-ichi-app](https://github.com/ongaeshi/a-hougan-ichi-app)

## 目的
子供の空間学習（「上から〜番目、右から〜番目」などの位置把握）をサポートするため。

## 概要
React + TypeScriptで作成されたWebアプリ。音声で指示された位置（例：「上から2番目、右から3番目」）のマス目をタップして正解を当てる学習ゲームです。
