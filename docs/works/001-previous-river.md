# 001: previous-river

- **URL**: [https://community.obsidian.md/plugins/previous-river](https://community.obsidian.md/plugins/previous-river)
- **コード**: [https://github.com/ongaeshi/previous-river](https://github.com/ongaeshi/previous-river)

## 目的
Obsidianのノートに連続した順序関係を持たせるため。

## 概要
Obsidianプラグイン。previousプロパティに前のノートへのリンクを設定することで、ノートを連続した流れ（Sequential）として繋いだり、構造化してナビゲーションしやすくします。
