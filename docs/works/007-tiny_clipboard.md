# 007: tiny_clipboard

- **コード**: [https://github.com/ongaeshi/tiny_clipboard](https://github.com/ongaeshi/tiny_clipboard)

## 目的
依存関係（gem）なしで、1ファイルのみで動作するRubyのクリップボード操作ライブラリを作るため。

## 概要
標準ライブラリとOSのコマンド（pbcopy, clip など）のみに依存するクリップボードライブラリ。プロジェクトのディレクトリに 	iny_clipboard.rb を置くだけで使えます。
