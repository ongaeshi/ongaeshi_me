# 003: ObsidianDailyAppender (oda)

- **コード**: [https://github.com/ongaeshi/ObsidianDailyAppender](https://github.com/ongaeshi/ObsidianDailyAppender)

## 目的
ターミナルから素早くObsidianのデイリーノートにテキストを追記するため。

## 概要
ターミナル上で動くCLIツール（C# / .NET）。コマンドラインから複数行のテキストを入力して、Obsidianのデイリーノートにタイムスタンプ付きで追記できます。

## 最初のプロンプト

```text
obsidianのデイリーノートに連続で複数行入力できるTUIツールをC#を使って作成したい。
- ソフトウェア名: Obsidian Daily Appender
- コマンド名: oda.exe (Obsidian Daily Appender の略)
- oda で実行するとTUIツールが起動
- Enterで入力した行を送信。Shift+Enterで複数行入力ができるようにしたい。
- 基本的な入出力の仕様は C:\Users\ongaeshi\Code\obsidian_tool\tweet.rb を参考にする。(obsidian CLI を経由して入力する形でOK)
```
